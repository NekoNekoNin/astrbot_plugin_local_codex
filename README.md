# NekoNekoNin · 本地 Codex 模型接入

在 AstrBot 中复用本机 Codex 登录，支持工具调用、流式回复、自动思考档位、请求进度和单条取消。

版本：`v1.2.4` · 许可：[MIT](LICENSE)

## 能做什么

- 使用已安装 Codex CLI 的本机登录会话，保持 AstrBot 的消息与工具流程。
- 自动按当前问题选择思考档位，也可手动固定；模型级设置优先。
- 支持普通与流式回复，提供请求阶段、实际档位和单条取消。

## 安装

在 AstrBot 的插件管理上传本插件发布 ZIP，或使用[本仓库地址](https://github.com/NekoNekoNin/astrbot_plugin_local_codex)安装。内部插件名保持 `astrbot_plugin_local_codex`，升级时沿用已有配置。元数据已绑定本仓库，更新时请核对版本与更新记录。

需要本机安装 Codex CLI 并自行完成登录。插件与 CLI 运行在同一用户环境；本插件需要 Python 3.11+。不随仓库分发账号凭据。

## 设置

入口：**AstrBot → 插件 → NekoNekoNin · 本地 Codex 模型接入 → 配置**。常用选项直接显示，适用时提供中文下拉标签、数值滑块、条件显示与高级折叠。完整选项见 [配置说明](docs/CONFIGURATION.md)。

## 聊天示例

- “日常问候，观察自动选择较轻档位。”
- “请深入分析这段代码的并发问题，观察实际思考档位。”

## 使用边界

固定档位受所选模型支持范围限制。模型级 Reasoning Effort 覆盖插件选项。取消不会撤回已发送消息或已经执行的外部动作。请求监控保留本次运行最近 200 条，重载后清空。

## 接入模型

安装插件后，在“模型提供商”添加“本地 Codex / OpenAI”类型，选择 CLI 实际支持的模型。需要切换已有聊天使用的模型时，由管理员在对应配置中选择；插件不会擅自替换其他服务商。

## 请求监控

已有“请求状态”页面保留，用于查看处理阶段与取消请求；思考档位在插件自身的“配置”入口管理。
