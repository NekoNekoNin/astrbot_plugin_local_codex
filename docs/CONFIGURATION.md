# 原生插件配置

入口：AstrBot → 插件 → **本地 Codex 模型接入** → **配置**。本版不新增独立 Web 设置页。

以 AstrBot 4.29.1 的原生配置组件核对下拉标签、滑块、条件显示与高级折叠。配置键保持兼容；保存会重载插件，正在处理的请求应先完成。

| 配置键 | 界面名称 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `reasoning_effort` | 模型 · 思考强度 | "auto" | 模型编辑里的 Reasoning Effort 优先于本项。自动模式按当前真实提问和短追问选择，不用工具结果重新定档；保存后从下一次新请求生效，实际档位受模型支持范围限制。 |
