# 原生插件配置

入口：AstrBot → 插件 → **本地 Codex 模型接入** → **配置**。普通设置无需独立 Web 页面。

保存会重载插件，请先等待正在处理的请求结束。

| 配置键 | 界面名称 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `reasoning_effort` | 模型 · 思考强度 | "auto" | 模型编辑里的 Reasoning Effort 优先于本项。自动模式按当前真实提问和短追问选择，不用工具结果重新定档；保存后从下一次新请求生效，实际档位受模型支持范围限制。 |
| `cli_path` | PC 接入 · Codex CLI 路径 | "" | 留空自动识别 Codex 桌面版附带程序或 PATH。手填 codex.exe、官方 npm 的 codex.cmd 或 codex.js 完整路径；不要填写命令参数或额外引号。保存前请等待正在处理的请求结束。 |
| `codex_home` | PC 接入 · Codex 用户目录 | "" | 留空使用 CODEX_HOME 环境变量或当前 Windows 用户的 .codex。自定义目录需先自行登录；插件不复制凭据。管理员发送 /codex状态 可检查连接、登录和模型目录。 |
